# IoT Smart Parking System

##  Project Overview
The IoT Smart Parking System is designed to monitor parking slot availability using sensors and display real-time parking information. It helps drivers identify available parking spaces easily.

## 🛠️ Components Used
- Arduino Uno
- ESP8266 Wi-Fi Module
- 4 IR Sensors
- 16x2 LCD Display
- Servo Motor
- Jumper Wires
- Power Supply

##  Technologies Used
- Arduino IDE
- Embedded C/C++
- Internet of Things (IoT)
- ThingSpeak
- ESP8266 Wi-Fi Communication

## ⚙️ Working Principle
1. IR sensors detect whether parking slots are occupied or available.
2. Arduino processes the sensor readings.
3. The LCD displays the number of available and occupied parking slots.
4. The servo motor controls the parking gate.
5. The ESP8266 sends parking information to the ThingSpeak IoT platform over Wi-Fi.
